Frequently asked questions

Questions? Start here.

Do I need coding experience?

No. Start with drag-and-drop building and visual CSS controls, then progress to CSS games and code editing.

Can I save my work and come back later?

Yes. Save editable projects as .codeblocks files and load them again to continue.

Can I open my finished websites in a browser?

Yes. Use Export Website to create an HTML file that can be opened in a web browser.

Does it teach mobile-friendly design?

Yes. Learn responsive layouts and test desktop, tablet and mobile previews.

How do I activate the application?

Follow the activation instructions provided with your copy of CodeBlocks Web Lab. For security, activation credentials are not published on this public website.
